TrustVault Security Standards Manifesto

Standard 1: Server-Side Authorization & 404 Concealment Anti-Enumeration

Permissions are never stored inside long-lived JWTs. Access is evaluated in real time against documents and document_grants. Revocation terminates access instantly. All unauthorized access attempts uniformly return 404 Not Found (never 403) to eliminate object probing and ID enumeration.

Standard 2: Cryptographic Audit Ledger SHA-256 Chaining

Every upload, download, permission grant, revocation, and denied attempt is immutably recorded in audit_ledger. Each row computes hash = SHA256(prev_hash + actor + action + doc + status + timestamp) from genesis (0000000000...). The /api/audit/verify endpoint recalculates the entire chain, reporting INTACT or pinpointing tampering.

Standard 3: Magic-Byte Header Validation Buffer Inspection

Uploaded files undergo raw byte buffer signature inspection (PDF %PDF, PNG \x89PNG, JPEG \xFF\xD8\xFF). Executables or malicious scripts disguised with spoofed extensions (such as MZ PE headers) are rejected with HTTP 400.
